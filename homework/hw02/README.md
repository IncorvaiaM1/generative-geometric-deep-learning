# Homework 2

Run scripts from `code`, e.g. `python em_mnist.py`. Clone the external pytorch-generative dependency into `code/pytorch-generative`, or install it so it is importable. The MNIST helper downloads its pickle if absent. NICE/VAE sampling requires regenerated model weights. Figures in `results` are archived outputs.

The archived writeup is [writeup/solutions.pdf](writeup/solutions.pdf). Compile `solutions.tex` from `writeup` with a LaTeX installation. Source-relative figures have been preserved. Benchmark material appearing in the writeup is maintained separately in gdl-benchmarks.
