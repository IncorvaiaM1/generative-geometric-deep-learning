# Homework 1

Run individual scripts from their own problem directory, e.g. `python problem1.py` inside `code/problem1`. For `code/problem5`, clone the external pytorch-generative dependency into that working directory, or install it so `pytorch_generative` is importable. Training outputs and weights must be regenerated.

The archived writeup is [writeup/hw1_complete.pdf](writeup/hw1_complete.pdf). Compile `hw1_complete.tex` from `writeup` with a LaTeX installation. Source-relative figures have been preserved. Benchmark material appearing in the writeup is maintained separately in gdl-benchmarks.
